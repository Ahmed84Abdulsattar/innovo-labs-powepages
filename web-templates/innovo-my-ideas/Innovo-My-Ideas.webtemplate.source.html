Dataverse Choice columns have to be set by option number from Power Automate, which would mean maintaining a label-to-integer map in the flow and would break the day someone adds an option in SharePoint. Nothing is hand-edited here, so the validation belongs in SharePoint where the editing happens. ── SECURITY ────────────────────────────────────────────────────────── Rows are scoped by the innovo_contact lookup.
